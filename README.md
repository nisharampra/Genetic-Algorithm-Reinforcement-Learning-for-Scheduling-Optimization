# 🧬 Genetic Algorithm + Reinforcement Learning for Scheduling Optimization

This project implements a hybrid optimization technique combining a **Genetic Algorithm (GA)** with **Reinforcement Learning (RL)** to dynamically adjust genetic parameters like **mutation probability** and **parent selection strategy**. The goal is to minimize the **makespan** in a simplified job scheduling scenario.

---

## 🚀 Features

- Genetic Algorithm with crossover and mutation
- Q-learning based RL agent to guide:
  - Parent selection strategy (`tournament` or `roulette`)
  - Mutation rate (`0.1` or `0.3`)
- Fitness improvement tracking
- Fully implemented in a Jupyter notebook (`app.ipynb`)

---

## 🛠️ Technologies Used

- Python
- NumPy
- PyTorch (for Q-learning)
- Jupyter Notebook
